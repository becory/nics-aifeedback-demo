# 一、AI 回饋系統管理後台功能列表

## A、登入頁面

| 頁面編號與名稱 | 功能編號 | 模組名稱 | 功能項目 | 功能說明 |
| --- | --- | --- | --- | --- |
| A1 登入與二階段驗證頁 | A1-01 | 身分驗證 | 帳號密碼登入 | 使用者輸入帳號與密碼進行登入，登入失敗時顯示錯誤訊息。 |
|  | A1-02 | 身分驗證 | 二階段驗證綁定（QR Code） | 首次登入且尚未綁定者，顯示 QR Code 供 Authenticator App 掃描，輸入 6 碼驗證後完成綁定；二階段驗證為強制項目，無法略過。 |
|  | A1-03 | 身分驗證 | 二階段驗證碼驗證 | 已綁定使用者於帳密登入後，輸入驗證器 App 產生之 6 碼驗證碼以完成登入。 |

## B、使用者頁面

| 頁面編號與名稱 | 功能編號 | 模組名稱 | 功能項目 | 功能說明 |
| --- | --- | --- | --- | --- |
| B1 回饋資料總覽頁 | B1-01 | 回饋分析 | 時間範圍篩選 | 提供多種預設時間區間切換（如今日、近 7 天等），驅動下方所有統計與圖表。 |
|  | B1-02 | 回饋分析 | 回饋數量趨勢圖 | 以折線圖呈現所選時間範圍內每日回饋數量，並同時顯示回饋總數與平均分數。 |
|  | B1-03 | 回饋分析 | 熱門流量多維度統計 | 依服務、組織、評價、來源國家/地區、ASN、IP 位址、主機、使用者代理程式、裝置等維度統計排行，可展開檢視完整清單。 |
|  | B1-04 | 回饋分析 | 篩選條件（納入/排除） | 於統計項目上可選擇「僅顯示此項目」或「排除此項目」，套用之篩選條件以標籤呈現，並支援一鍵清除全部篩選。 |
|  | B1-05 | 審核與紀錄 | 活動記錄查詢 | 顯示回饋活動記錄列表，依目前篩選條件即時更新，支援分頁瀏覽，單筆可行內展開完整詳情（Session ID、IP、裝置、評論等）。 |
|  | B1-06 | 審核與紀錄 | 顯示欄位自訂 | 可自訂活動記錄表格顯示欄位（時間、評價、國家、IP、主機、服務、使用者代理程式、裝置、Session ID、回饋評論等），設定保留於瀏覽器本機。 |
| B2 匯入資料頁 | B2-01 | 資料匯入 | 上傳加密資料檔匯入 | 使用者上傳由其他地方匯出的資料檔，系統僅接受經後端加密之檔案；若偵測資料遭篡改則拒絕匯入並顯示錯誤訊息。 |
|  | B2-02 | 資料匯入 | 匯入紀錄查詢 | 顯示歷次匯入紀錄，包含匯入時間、檔名與匯入結果（成功／失敗／驗證失敗等）。 |
| B3 組織清單頁 | B3-01 | 組織檢視 | 所屬組織清單檢視 | 一般使用者可檢視自己所屬的組織清單（唯讀），顯示組織名稱與代碼。 |
| B4 服務清單頁 | B4-01 | 服務檢視 | 所屬服務清單檢視 | 一般使用者可檢視自己所屬組織下的服務清單（唯讀），顯示服務名稱、所屬組織、服務代碼與網域。 |
| B5 修改密碼頁 | B5-01 | 身分權限 | 使用者自行變更密碼 | 登入者輸入目前密碼、新密碼與確認密碼即可自行變更密碼，無須管理員介入；新密碼不可與目前密碼相同。 |
|  | B5-02 | 身分權限 | 自行解除二階段驗證綁定 | 使用者需輸入目前密碼後按下「解除綁定」按鈕，並於彈出對話框二次確認，即可解除目前之二階段驗證綁定；解除後下次登入須重新掃描 QR Code 綁定新的二階段驗證。 |

## C、管理員頁面

| 頁面編號與名稱 | 功能編號 | 模組名稱 | 功能項目 | 功能說明 |
| --- | --- | --- | --- | --- |
| C1 組織管理頁 | C1-01 | 組織管理 | 組織清單檢視 | 顯示系統中所有組織之名稱與代碼。 |
|  | C1-02 | 組織管理 | 新增／編輯組織 | 以彈出視窗表單新增或編輯組織名稱與代碼，代碼儲存時自動轉換為大寫。 |
|  | C1-03 | 組織管理 | 刪除組織 | 刪除時需彈出對話框二次確認。 |
| C2 服務管理頁 | C2-01 | 服務管理 | 服務清單檢視 | 顯示各組織下之服務名稱、所屬組織、服務代碼與網域。 |
|  | C2-02 | 服務管理 | 新增／編輯服務 | 表單填寫服務名稱、所屬組織（下拉選擇）、服務代碼與網域，代碼自動轉大寫、網域自動轉小寫；尚無組織時無法新增服務。 |
|  | C2-03 | 服務管理 | 刪除服務 | 刪除時需二次確認。 |
| C3 離線金鑰頁 | C3-01 | 金鑰管理 | 離線金鑰清單檢視 | 顯示各組織之離線金鑰、說明、AES KEY、到期時間與有效／已過期狀態。 |
|  | C3-02 | 金鑰管理 | 新增離線金鑰 | 選擇所屬組織並設定到期時間（預設為一年後），儲存後系統自動產生一組 256-bit AES KEY（Base64 編碼）；一個組織可擁有多把金鑰。 |
|  | C3-03 | 金鑰管理 | 編輯離線金鑰 | 可編輯金鑰說明與到期時間，所屬組織與已產生之金鑰內容不可變更。 |
|  | C3-04 | 金鑰管理 | 金鑰複製 | 一鍵複製 AES KEY 至剪貼簿，方便部署使用。 |
|  | C3-05 | 金鑰管理 | 刪除離線金鑰 | 刪除時需二次確認。 |
| C4 使用者管理頁 | C4-01 | 身分權限 | 使用者清單檢視 | 顯示使用者中文名稱、信箱、所屬組織、二階段驗證狀態（已綁定／待綁定）與管理員標記。 |
|  | C4-02 | 身分權限 | 新增使用者 | 表單填寫中文名稱、信箱、初始密碼、所屬組織（可多選）、是否為管理員。 |
|  | C4-03 | 身分權限 | 編輯使用者 | 可編輯中文名稱、信箱、所屬組織與管理員權限。 |
|  | C4-04 | 身分權限 | 管理員代為修改密碼 | 管理員可直接為指定使用者設定新密碼，需輸入並確認兩次一致後方可送出。 |
|  | C4-05 | 身分權限 | 重設二階段驗證 | 管理員可重設使用者之二階段驗證綁定，該使用者下次登入時須重新掃描綁定；操作前需二次確認。 |
|  | C4-06 | 身分權限 | 刪除使用者 | 刪除時需二次確認；系統至少須保留一位管理員帳號，無法刪除唯一的管理員。 |
| C5 分數管理頁 | C5-01 | 分數管理 | 評價分數清單檢視 | 依 good／normal／bad 三種評價代碼，列出對應之中文名稱、中文說明與分數。 |
|  | C5-02 | 分數管理 | 編輯評價分數設定 | 可編輯中文名稱、中文說明與分數（0～100），回饋總覽頁之平均分數即依此設定計算。 |

## 全域元件（版面配置）

| 頁面編號與名稱 | 功能編號 | 模組名稱 | 功能項目 | 功能說明 |
| --- | --- | --- | --- | --- |
| 版面配置（全域元件） | G1-01 | 導覽 | 依角色顯示側邊導覽選單 | 一般使用者顯示「使用者功能」（回饋資料總覽、匯入資料、組織清單、服務清單）；管理員額外顯示「管理員功能」（組織管理、服務管理、離線金鑰、使用者管理、分數管理）。 |
|  | G1-02 | 帳號 | 帳號選單 | 顯示使用者姓名、信箱與管理員標記，並提供修改密碼、登出等操作入口。 |
|  | G1-03 | 權限控管 | 路由存取保護 | 未登入或尚未完成二階段驗證者，自動導向登入頁或對應驗證頁；非管理員嘗試存取管理頁面時，自動導向服務清單頁。 |
